# KajadhEcommerceApplication
Description:
This is a full-stack Online Store Application developed using Java technologies and standard web development tools. The application implements the Model-View-Controller (MVC) pattern with Servlets/JSP for the frontend, Hibernate ORM for database operations, and Spring Core for dependency injection and application context management. The project also incorporates HTML/CSS for a user-friendly interface.

Features:
User Management:
User registration and login functionalities.
Validation for secure and robust data handling.
Product Management:
Add, view, update, and delete products.
Separate user and admin roles for restricted access.
Cart Functionality:
Add products to the cart and manage quantities.
Calculate total price dynamically.
Order Management:
Place orders and view order history.
Payment gateway integration (future enhancement).
Database Integration:
Used Hibernate for seamless interaction with the database.
Designed schema for users, products, orders, and carts.
Spring Core Features:
Dependency injection for service classes and DAOs.
Lifecycle management for beans.
Responsive UI:
Built with HTML and CSS for a clean and intuitive design.
